## API PARA AGREGAR OFERTAS

### FLUJO DE TRABAJO
1. Encontrar oferta en LinkedIn/Computrabajo/RemoteOK/etc.
2. Evaluar con filtros duros (edad, idioma, ubicación, stack)
3. Clasificar: IDEAL (salary ≥$2,200) o BACKUP (salary bajo/no publicado)
4. **ENViar POST a la API** con los datos de la oferta
5. Reportar a Carlos con resumen

### Endpoint
```
POST http://localhost:3000/api/jobs
```

### Body JSON - Estructura de Oferta
```json
{
  "title": "string (requerido) - Título del puesto",
  "company": "string (requerido) - Nombre de la empresa",
  "url": "string - Link a la oferta (requerido)",
  "salary": "number - Salario base USD/mes (null si no publicado)",
  "salaryMax": "number - Salario máximo (null si igual al base)",
  "currency": "string - Moneda (USD, EUR, etc.)",
  "modality": "string - Remoto | Presencial | Híbrido",
  "location": "string - Ubicación (LatAm, Colombia, El Salvador, etc.)",
  "stack": "array[string] - Tecnologías (Flutter, Laravel, Angular, etc.)",
  "date": "string - Fecha publicación (YYYY-MM-DD)",
  "daysAgo": "number - Días desde publicación",
  "notes": "string - Notas: evaluación, por qué es ideal/backup, cosas a verificar",
  "isIdeal": "boolean - true = IDEAL, false = BACKUP",
  "applied": "boolean - false (por defecto, Carlos aplica después)",
  "cvRequested": "boolean - false (por defecto)",
  "interview": "string (opcional) - Fecha entrevista si ya está programada"
}
```

### Ejemplo - Oferta IDEAL encontrada
